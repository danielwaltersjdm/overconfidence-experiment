# Dependency policy - read before changing a version here.
#
# Only `anthropic` is pinned exactly, because only `anthropic` has broken this
# study: around 2026-08-21 it went to 1.x and migrated from httpx to httpx2,
# which made every Claude call raise TypeError for 33 days.
#
# Everything else carries a floor plus a major-version ceiling. An earlier
# attempt (2026-09-23) pinned all ten packages to exact versions resolved on a
# local Python 3.12 box. CI runs Python 3.11, numpy 2.5.x requires >=3.12, so
# `pip install` failed outright and killed collection for ALL THREE models for
# 18 weekdays - worse than the bug it was fixing. Pin narrowly; a ceiling stops
# a major-version surprise without inventing a Python-version conflict.
#
# Verified 2026-10-16 to resolve under Python 3.11 (what CI uses):
#   anthropic 1.3.0, httpx2 2.13.1, openai 3.31.0, google-genai 2.31.0,
#   yfinance 1.7.0, pandas 3.0.6, numpy 2.4.6, rich 15.0.0
# Re-verify after any change with:
#   pip install --dry-run --python-version 3.11 --only-binary=:all: \
#       --target /tmp/x -r study4/requirements.txt
